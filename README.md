# Token Games (TTG)

Idle games that play themselves from the work your AI agent does: every token spent or task finished moves the game forward. Works with Claude Code first, then Codex and other agents.

Planned:
- Tower defense: tokens queue enemies, a bucket releases them in waves.
- Ant farm: seeded maps with food scattered through them, the ants tunnel to find it. Design: [docs/ant-farm-design.md](docs/ant-farm-design.md). Prototype: [prototype/ant-farm](prototype/ant-farm/).
- A website where people find, upload and link their own agent idle games.
